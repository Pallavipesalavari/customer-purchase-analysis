# Contributing

Contributions and suggestions are welcome.

## Suggested workflow
1. Fork the repository.
2. Create a branch for your change.
3. Keep changes focused and use clear file names.
4. Test the Streamlit app locally with the default data and a valid CSV.
5. Update the documentation if the app's inputs or behavior change.
6. Submit a pull request describing the change and how it was tested.

## Data and privacy
Do not commit private, confidential, or personally identifying customer data.
Use synthetic or appropriately anonymized sample data in public examples.
