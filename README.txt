CUSTOMER PURCHASE PATTERN ANALYSIS - STREAMLIT APP

Files:
  app.py            Streamlit dashboard
  requirements.txt  Python packages used by the app

ONLINE OPTION (no software installation on your Windows laptop):
1. Create or sign in to a GitHub account.
2. Create a new repository.
3. Upload app.py and requirements.txt to the repository root.
4. Open https://share.streamlit.io/ and sign in with GitHub.
5. Choose New app, select your repository and branch, and set the main file path to app.py.
6. Deploy. Streamlit Community Cloud installs the listed requirements in its hosted environment.

LOCAL OPTION (requires Python and package installation):
  pip install -r requirements.txt
  streamlit run app.py
CSV columns required:
  Customer_ID, Customer_Name, Product, Quantity, Price
